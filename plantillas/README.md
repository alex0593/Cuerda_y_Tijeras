## Regla de uso

1. Crear una ficha nueva por cada elemento.
2. Mantener el estado: `idea`, `prototipo`, `producción`, `aprobado` o `descartado`.
3. No publicar un elemento que no tenga una prueba de lectura o funcionamiento.
4. Registrar la fecha de cada cambio importante.
5. Enlazar la ficha con el documento general cuando el elemento pase a producción.
